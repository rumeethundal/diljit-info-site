# Diljit Concert Website

A responsive informational website designed to provide users with details about a Diljit Dosanjh concert.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Responsive website layout
- Concert information and event details
- RSVP form with client-side input validation

## Getting Started
1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## About the Project
This project was developed to practice front-end web development, responsive design, and JavaScript form handling.
